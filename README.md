
This is a web application built with React and TensorFlow.js that allows you to perform real-time object detection using your webcam.

## Setup and Local Run
1.  **Navigate to the project directory:** Open your terminal or command prompt and navigate to the extracted project folder:
    ```bash
    cd tfjs-object-detection-app
    ```
2. **Install dependencies:** Install the necessary Node.js packages using pnpm (if you don't have pnpm, you can install it via `npm install -g pnpm`):
    ```bash
    sudo apt install nodejs -y
    node -v
    sudo apt install npm -y
    sudo npm install -g pnpm
    pnpm install
    ```


3. **Run the application:** Start the development server. Make sure port `5173` is open and accessible on your machine.
    ```bash
    pnpm run dev --host
    ```

4.  **Access the application:** Open your web browser and go to `http://localhost:5173`.
